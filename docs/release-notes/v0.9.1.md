# Scroblytics 0.9.1 (beta)

A fix for first imports that stopped partway, plus a notice when a newer version is available.

## Fixed

- **A first import could stop with "Last.fm is rate-limiting requests."** Last.fm allows about five requests a second, and on a fast or
  shared connection the app could exceed that, then gave up after about 15 seconds. Now:
  - The app spaces its requests to Last.fm, so it stays under the limit in the first place. Background lookups (tags, popularity) share
    that budget, and the import goes first.
  - If Last.fm still says "slow down", the app **waits and carries on by itself** (30 seconds, then a minute at a time, for up to ten
    minutes), and the top bar says so. **Stop** still works at any time. If Last.fm keeps refusing for ten minutes, the import stops with
    a clearer message and a Retry button; everything already imported is kept.
  - **If your import stopped on 0.9.0:** install this version and press **Retry** (or just open the app). It carries on where it stopped.
- The first import can take a little longer on a very fast connection, because of the spacing; on a typical connection the difference is
  a few percent.

## New

- **Update notice.** Once a day Scroblytics asks GitHub whether a newer version has been released and, if so, shows a strip with a link to
  the release page. It never downloads or installs anything. **Scroblytics › Check for Updates…** checks right away, and **Settings ›
  General › Updates** turns the daily check off. Offline mode stops it. See the updated [privacy policy](https://github.com/scrobl/Scroblytics/blob/main/PRIVACY.md).
- Help: a new article, "Updating Scroblytics", and updated pages on syncing and on what leaves your Mac.

## Requirements and install

Unchanged: macOS 15 or later (Apple silicon or Intel), a free Last.fm API key. Download `Scroblytics-0.9.1.dmg` below, open it and drag
**Scroblytics** to **Applications**, replacing the old copy. Your data stays where it is. To verify the download, compare its SHA-256 with
the attached `Scroblytics-0.9.1.dmg.sha256` (`shasum -a 256 Scroblytics-0.9.1.dmg`).
