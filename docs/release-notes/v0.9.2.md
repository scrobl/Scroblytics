# Scroblytics 0.9.2 (beta)

A fix for a crash that could happen during the first import on macOS 15.

## Fixed

- **The app could quit by itself, a few minutes into the first import or while artwork was being fetched, on macOS 15 (Sequoia).**
  The cause was on the Overview page: its "Top tags" card looked up several artists' tags at the same moment, and it started that again
  on every 30-second refresh while the import was still running. That could abort the app on macOS 15. The tag lookups now run one at a
  time (they were already spaced out, so nothing is slower), and only one tag run is active at once.
  - **If this happened to you:** install this version and open it. Nothing was lost. The import carries on where it stopped, and the
    Overview fills in as it goes.
  - The crash was reproduced on macOS 15 (Apple silicon). It may also have been behind similar quits on other versions, so everyone should update.

## Also in this release

Nothing else has changed. If you're on 0.9.1 the app will tell you about this version (a strip under the toolbar, or
**Scroblytics › Check for Updates…**).

## Requirements and install

macOS 15 or later (Apple silicon or Intel) and a free Last.fm API key, as before. Download `Scroblytics-0.9.2.dmg` below, open it and drag
**Scroblytics** to **Applications**, replacing the old copy. Your data stays where it is. To verify the download, compare its SHA-256 with
the attached `Scroblytics-0.9.2.dmg.sha256` (`shasum -a 256 Scroblytics-0.9.2.dmg`).
