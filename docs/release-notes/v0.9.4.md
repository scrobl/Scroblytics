# Scroblytics 0.9.4 (beta)

A performance release for very large listening histories.

## Fixed

- **Pages no longer redo all their work every time background lookups report progress.** While Scroblytics works through a long backlog of
  lookups (tags, track lengths, release dates), it announces progress every few seconds. Trends threw its data away and recalculated every
  chart each time, and a recalculation that had been replaced kept running on top of the next one. On a very large history that left Trends
  loading with several processor cores busy, and the Mac hot. Trends, Query, Top Charts and Timeline now refresh for background progress at
  most every few minutes (and as soon as you open the page), and Trends runs a couple of chart calculations at a time and skips one that
  has been replaced.
- **The listening history is read once and shared.** Every page used to read the whole history for itself, so opening a page cost seconds
  of processor time and each page held its own copy in memory. The app now keeps one copy for all of them, and checks cheaply whether it is
  still current. Memory no longer grows as you visit more pages.
- **Overview starts faster on a big library.** Several things that went through the whole history again for every card or every row
  (trend lines, the Most Recent / Most Often list, streaks, a picture check run once per play) now do it in one pass, with the same results.

In my testing, on a copy of a library enlarged to 366,000 plays, the app used about 20 seconds of processor time at launch (it was about 40),
and opening Milestones, Timeline and Trends cost two to five times less. Very large libraries are still heavier than small ones. If the app
is slow or hot for you, **Help › Report a Problem…** includes how much memory it is using.

## Requirements and install

macOS 15 or later (Apple silicon or Intel) and a free Last.fm API key, as before. Download `Scroblytics-0.9.4.dmg` below, open it and drag
**Scroblytics** to **Applications**, replacing the old copy. Your data stays where it is. To verify the download, compare its SHA-256 with
the attached `Scroblytics-0.9.4.dmg.sha256` (`shasum -a 256 Scroblytics-0.9.4.dmg`). If you're on 0.9.3 or earlier the app will tell you
about this version (a strip under the toolbar, or **Scroblytics › Check for Updates…**).
